Q2STATS · DEVELOPMENT

Project Status & Roadmap

Last updated: October 26, 2026

Q2Stats is a community project under active development. We are improving match collection, player statistics and ratings, with feedback from players and server owners.

Development and testing

The rating system needs to be evaluated across real matches and may require adjustments as we learn more about its behaviour. Our goal is to refine a consistent, reliable model rather than repeatedly replace the rating engine. We are working towards what we believe provides the fairest assessment of player performance.

We are aware of existing bugs and are improving data collection, server integration and the accuracy of recorded statistics.

What we are working on

  • Reliable match collection: improving how statistics are received and processed.
  • Rating validation: reviewing match calculations and evaluating whether the model produces consistent and meaningful results.
  • Player identities: improving nickname and profile handling.
  • Match demos: making MVD2 demos available directly from match pages where supported.
  • More servers: we hope to connect more servers to Q2Stats as the updated integration becomes available.

Known issues

Missing or delayed matches

With the client-based collection method, statistics can remain buffered in the client until a new match starts, delaying their submission to Q2Stats.

Previously, matches were also withheld from submission if complete player statistics were unavailable—for example, when a player disconnected before the match ended. The updated OpenTDM integration addresses these issues by reporting statistics directly from the server.

Missing statistics after a disconnect

A player disconnecting before the end of a match can still result in incomplete or missing player statistics with the current collection method. The updated OpenTDM version will resolve this by retaining their match statistics after they disconnect.

Demo availability

MVD2 demos depend on server support and may become available later than the match statistics.

What comes next

An updated version of OpenTDM, being developed and tested with Claire, will allow server owners to submit match statistics directly to Q2Stats.

As testing progresses, we plan to expand this integration to more servers and publish setup instructions for server owners who want to participate. Direct server reporting will make collection more reliable and reduce dependence on spectator bots and the Q2Stats server uploader.

Help us improve Q2Stats

When reporting a problem, please include the match link or ID, server, map and approximate time.
